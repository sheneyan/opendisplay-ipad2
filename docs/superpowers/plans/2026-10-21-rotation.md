# Automatic orientation implementation plan

**Superseded:** the user approved manual Rotate 90° instead. See the manual-rotation design/plan dated October 21, 2026. This document preserves the failed automatic-orientation trial.

**Goal:** Build 10 rotates iPad 2 and mini 2 desktops with the physical device and preserves existing touch/settings behavior.

**Architecture:** UIKit reports its full-screen bounds orientation to ODReceiver. ODDisplaySettings swaps all dimension pairs; the receiver retires the old session after a 0.6-second debounce, preserves the listener, and rejects old input until the fresh hello. Touch uses matching decoded-video geometry, and the mini table formats saved presets for the current orientation.

**Tech stack:** Objective-C, UIKit iOS 9/12, Foundation TCP tests, H.264, libimobiledevice.
